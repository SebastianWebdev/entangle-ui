### Phase 3.3 — CommandPalette ✅ (flagship)

Located at `src/components/feedback/CommandPalette/`. Commit `3edf83e`.

- Pure fuzzy matcher in `fuzzySearch.ts` (subsequence + word-boundary + position scoring); also exported as `fuzzyScore` / `fuzzyFilter` from package root

## Conventions confirmed across sessions

- `BaseComponent<HTMLDivElement>` from `@/types/common`
- `Prettify<T>` for exported props types
- `Omit<BaseComponent<...>, 'title'>` whenever the component takes a `title: ReactNode` prop (clashes with HTMLAttributes); same trick for `'onSelect'` (CommandPalette) and `'children'` (Drawer.CloseButton)
- Vanilla Extract `recipe` for variant logic; `createVar` + `assignInlineVars` for runtime values (e.g., per-instance colors)
- Compound components with `Object.assign(Root, { Sub1, Sub2 })` (Card, HoverCard, Drawer)
- For unions accepting an open string with autocomplete on a few presets: `'sm' | 'md' | 'lg' | 'xl' | (string & {}) | number` — the bare `string` was being collapsed by ESLint's `no-redundant-type-constituents` rule
- `'use client'` directive at top of every component file
- `displayName` set explicitly on every component (including compound sub-components like `Drawer.Header`)
- `/*#__PURE__*/` annotations on `React.memo` and `createContext` calls
- Tests: `renderWithTheme` from `@/tests/testUtils`; describe blocks Rendering / Interactions / Accessibility (or domain-specific blocks like `Filtering`, `Keyboard navigation`)
- For Floating UI hover tests: fire `mouseenter`/`mouseleave` (not `pointerenter`/`pointerleave`) — `useHover` listens directly to mouse events on the reference element
- `cx` from `@/utils/cx` for class merging
- Stories: `Meta`/`StoryObj` from `@storybook/react`; one `Default` + variant stories
- After each component: `npm run lint` clean, `npx tsc --noEmit` clean, `npx vitest run` clean, then changeset (`npx changeset`), then per-component commit
- No non-null assertions in tests — replace `instances[0]!` with explicit `if (!x) throw new Error(...)` to satisfy `@typescript-eslint/no-non-null-assertion`

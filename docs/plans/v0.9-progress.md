## Conventions confirmed in this session

- `BaseComponent<HTMLDivElement>` from `@/types/common`
- `Prettify<T>` for exported props types
- `Omit<BaseComponent<...>, 'title'>` whenever the component takes a `title: ReactNode` prop (clashes with HTMLAttributes)
- Vanilla Extract `recipe` for variant logic; `createVar` + `assignInlineVars` for runtime values (e.g., per-instance colors)
- Compound components with `Object.assign(Root, { Sub1, Sub2 })` (see Card)
- `'use client'` directive at top of every component file
- `displayName` set explicitly on every component
- `/*#__PURE__*/` annotations on `React.memo` and `createContext` calls
- Tests: `renderWithTheme` from `@/tests/testUtils`; describe blocks Rendering / Interactions / Accessibility
- `cx` from `@/utils/cx` for class merging
- Stories: `Meta`/`StoryObj` from `@storybook/react`; one Default + variant stories
- After each component: `npx tsc --noEmit` and `npx vitest run <path>` clean
- Per-component commit on the working branch with a short why-focused message

Add LLM-friendly documentation and a Claude Code skill.

The Astro docs now publish plain-text resources alongside the rendered site:

- `/llms.txt` — short index following the [llmstxt.org](https://llmstxt.org/) convention.
- `/llms-full.txt` — the full documentation as one concatenated text file.
- `/llms/<slug>.md` — every page exported as plain markdown (JSX demos stripped).

A new Getting Started page (Docs for LLMs) explains how to point AI assistants at these resources.

For Claude Code users, the repository now ships a structured skill at `.claude/skills/entangle-ui/`. Each component, hook and guide gets its own reference file so the assistant only loads the docs it needs:

- `components/<category>/<name>.md`
- `hooks/<name>.md`
- `guides/<name>.md`
- `reference/<...>.md`

All artefacts are regenerated by `docs-site/scripts/generate-llms-txt.mjs`, which runs automatically before `npm run dev` and `npm run build` in the docs site.
